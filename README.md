# IRCTC-Booking-Revenue-Analysis-Dashboard-
An interactive 3-page Power BI dashboard project designed to analyze railway booking data and uncover insights into revenue performance, booking trends, customer booking behavior, and demand across stations and routes. The project uses Power BI, DAX, and Power Query to track key performance indicators (KPIs), analyze booking status and cancellations, compare revenue across travel classes and routes, and identify monthly demand patterns.

Key Highlights

Analyzed 20,000 railway booking records.

Monitored total revenue, revenue per booking, confirmation rate, and cancellation rate.

Compared booking demand across routes, source stations, and travel classes.

Analyzed monthly booking trends and booking channels.

Created interactive visuals to support data-driven business decisions.

Tools & Technologies: Power BI, DAX, Power Query, Excel, SQL
